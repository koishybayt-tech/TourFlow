# 04. Дизайн-система и анимации

Цель — спокойный современный B2B-интерфейс (уровень Linear / Attio / Notion), в котором менеджер с первого взгляда понимает, что делать дальше. Прототип задаёт структуру и плотность; в продакшене — дороже, мягче и живее.

## Принципы

1. **Одно главное действие на экране.** Primary-кнопка одна, остальные — вторичные/ghost.
2. **Показывать только то, что требует работы.** Готовые блоки свёрнуты, пустые состояния ведут к действию.
3. **Состояние видно цветом и иконкой**, а не только текстом: серый — не начато, синий — в работе, зелёный — готово, оранжевый — внимание, красный — проблема.
4. **Числа — табличные цифры** (`font-variant-numeric: tabular-nums`), суммы выровнены вправо.
5. **Никакого «прилипания»:** контент страницы в контейнере с отступами `px-6 lg:px-8`, `py-6`, на всю ширину (без max-width на широких экранах — нужно для 4K), карточки с `p-5`/`p-6`.

Каналы: WhatsApp — зелёный, Instagram — розово-малиновый, Сайт — серый.

- Шрифт: **Inter** (кириллица + казахские буквы ә ғ қ ң ө ұ ү һ і — проверить), 14px базовый, заголовки страниц 22–24px/600, заголовки карточек 15px/600, подписи 12.5px.
- Радиусы: кнопки и поля 8px, карточки 12px, модалки 16px, бейджи 6px.
- Тени: карточки — без тени + граница; всплывающие — `0 12px 32px rgba(16,24,40,.14)`.
- Иконки: Lucide (`@iconify-json/lucide` через Nuxt UI), 16–18px, stroke 2.
- Тёмная тема — обязательно (Nuxt UI color-mode), переключатель в меню профиля.

## Компоненты (Nuxt UI + свои)

- `AppShell` (сайдбар + шапка), `PageHeader` (заголовок, подзаголовок, действия), `StatCard`, `StatusBadge`, `ChannelBadge`, `MoneyText`, `Avatar`, `EmptyState` (иконка, текст, CTA), `StepSection` (пронумерованный сворачиваемый блок заявки), `StickyStepsNav`, `KanbanBoard` (dnd: `vue-draggable-plus` или `@vueuse/integrations/useSortable`), `DataTable` (Nuxt UI `UTable`), `DocumentPreview` (A4-лист), `SlideOver` (карточка задачи), `CommandPalette` (⌘K).
- Формы: Nuxt UI `UForm` + Zod, ошибки под полем, маски: телефон `+7 (7XX) XXX-XX-XX`, ИИН/БИН 12 цифр, ИИК `KZ` + 18, суммы с разделителем тысяч.

## Анимации (Motion for Vue — `motion-v`, плюс CSS-переходы)

Анимации помогают понять, что произошло, а не украшают. Длительность 150–250 мс, `ease-out`, без «прыжков». Уважать `prefers-reduced-motion` (отключать перемещения, оставлять только opacity).

| Где | Анимация |
|---|---|
| Переход между страницами | fade + сдвиг 8px по Y (Nuxt `pageTransition`) |
| Появление списков и карточек | stagger 30 мс, fade + 6px |
| Сворачивание блока заявки | высота auto (layout-анимация), стрелка поворачивается |
| Автосмена статуса заявки | бейдж статуса «перетекает» (layout + цвет), короткий confetti-пульс на зелёном ✓ шага, toast снизу |
| Канбан | карточка поднимается при захвате (scale 1.02, тень), колонка подсвечивается при наведении |
| Прогресс оплаты | полоса растёт от старого значения к новому, сумма «досчитывается» (count-up 400 мс) |
| Модалки и SlideOver | fade фона + scale 0.98→1 / выезд справа |
| Скелетоны | shimmer при загрузке вместо спиннеров (спиннер только в кнопке) |
| Toast | снизу по центру, авто-скрытие 3,2 с, стек |
| Поиск туров | результаты появляются по мере ответа провайдеров (stagger), прогресс «опрашиваем операторов» |
| Подписание | галочка подписи рисуется (stroke-dashoffset), статус подписанта плавно меняется |

## Тексты интерфейса

- Кнопки — глаголы: «Принять оплату», «Сформировать договор», «Взять в работу».
- Ошибки — что сделать: «Укажите ИИН — 12 цифр», а не «Ошибка валидации».
- Пустые состояния — одна строка пользы + действие.
- Никаких «Сделка», только «Заявка».

## Адаптивность

Desktop first (менеджеры работают за компьютером), но всё должно работать на телефоне: сайдбар — drawer, таблицы — горизонтальный скролл в своём контейнере или карточки, правая колонка заявки — под основными блоками, канбан — горизонтальный скролл с snap.

## Доступность

Контраст AA, фокус-кольца, все интерактивные элементы — `button`/`a`, `aria-label` у иконок-кнопок, переключатели — `role="switch"`, модалки ловят фокус, Esc закрывает.
