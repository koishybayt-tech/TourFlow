# Changelog

## v0.1.0 — первая рабочая версия

Собрана по пакету передачи (`docs/HANDOFF.md`) за 11 фаз. Решения по ходу работы — в `docs/DECISIONS.md`.

### Ядро
- Вход по email или телефону, регистрация агентства (воронки, регламенты и шаблоны создаются автоматически), восстановление пароля, приглашения сотрудников.
- Роли Владелец / Менеджер / Колл-центр с проверкой прав на сервере; изоляция данных организаций.
- Оболочка с меню, поиском (⌘K или `/`), уведомлениями (живые обновления по SSE), тёмной темой.
- «Мой день»: ждут ответа, задачи на сегодня, календарь, оплаты и вылеты на неделе.

### Сообщения и клиенты
- Единая лента WhatsApp, Instagram и формы сайта; рекомендация воронки (метка ссылки → канал → ключевые слова) и направления; создание заявки из диалога с распределением по ответственным (по очереди, отпуска, резерв).
- Вебхуки WhatsApp Cloud API и Instagram с проверкой подписи; mock-провайдер и «тестовое сообщение» для демо.
- Клиенты: список с фильтрами и дублями, досье, объединение, просмотр ИИН с записью в журнал.

### Заявки
- Канбан с перетаскиванием и список; страница заявки с 8 блоками и правой колонкой «Статус / Осталось…».
- Автостатус на сервере после каждого изменения; системные задачи этапов; задачи только кнопками.
- Оплаты, возврат / перенос / замена, документы в S3, заметки, неизменяемая история.
- Редактор регламентов этапов.

### Документы и подписание
- Шаблоны DOCX с переменными `{…}` и автосвязкой с полями, предпросмотр на демо-заявке.
- Мастер «Документ на подпись», PDF через Gotenberg, ссылки клиенту и агентству.
- Публичная страница подписания: ЭЦП через NCALayer (реальный, если запущен) и eGov Mobile по QR (mock-проверка).
- Расписки по условиям, отправка рекомендуемых одной ссылкой, скан бумажных.

### Групповые туры
- Конструктор с 7 вкладками и автосохранением, финансовый калькулятор (план/факт, курсы, сценарии), Excel.
- Публикация с проверками → выезд; публичная страница тура с кнопкой WhatsApp.
- Выезды: сетка мест, шаги участников из этапов заявок, автозадачи, подбор гида.

### Пакетные туры
- Поиск туров с расселением по номерам (mock, каркас Tourvisor).
- Подборка: варианты с наценкой, импорт из текста или скриншота (Claude), отправка клиенту, «Клиент выбрал».
- Бронь у туроператора с оплатами, аннуляцией и предупреждением о кассовом разрыве; реестр броней.
- Авиабилеты и отели: поиск по источникам, мониторинг цен.

### Календарь, уведомления, отчёты
- Календарь (месяц / неделя / список) с автособытиями и проверкой пересечений; напоминания.
- Telegram-бот для сотрудников.
- Отчёты владельца: 9 показателей, 7 вкладок с графиками, Excel, еженедельная рассылка.

### Инфраструктура
- Docker Compose для разработки и продакшена (Caddy с HTTPS, ежедневные бэкапы), CI в GitHub Actions, образ в GHCR.
- 55 юнит-тестов доменной логики, 20 e2e-сценариев.

### Известные ограничения
- Реальные WhatsApp, Instagram, Tourvisor, проверка ЭЦП НУЦ РК и источники авиабилетов подключаются ключами и адаптерами (см. `deploy/README.md`).
- Тексты договоров и расписок — черновики, их нужно согласовать с юристом.
- Казахский язык интерфейса — только ключи i18n.
