# Фаза 4. Сообщения, клиенты, распределение

- Сообщения (§3): лента, фильтры, диалог, ответ (MessagingProvider mock; вебхук-эндпоинты WhatsApp Cloud API и Instagram — каркас с проверкой подписи), шаблоны ответов, данные лида.
- Определение воронки и направления (`server/domain/routing.ts`), полоса рекомендации в одну строку + выпадающий список воронки, создание заявки из диалога с поиском клиента по телефону.
- Клиенты (§6): список с фильтрами, досье, объединение дублей, редактирование (применяется ко всем заявкам).
- Настройки → Распределение по воронкам (ссылки с метками и генерация wa.me), Направления и ответственные, отпуска, «Проверить распределение».
- Realtime: новые сообщения и уведомления через SSE (Nitro event stream).

**Порядок работы:** сначала покажи план (файлы, модели, компоненты, риски) и дождись моего «ок». Потом реализация маленькими коммитами в ветке `feat/04-inbox`. В конце: `pnpm lint && pnpm typecheck && pnpm test` зелёные, краткий отчёт «что сделано / как проверить / что осталось», открой PR.
