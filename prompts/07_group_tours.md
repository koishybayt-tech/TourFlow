# Фаза 7. Групповые туры: конструктор, выезды, гиды, публикация

По `docs/02_FEATURES.md` §11 и ТЗ `reference/experts/TZ_FeelFreeTravel.docx`, программа Швейцарии — `reference/experts/guide_switzerland_march.txt`.
- Мои туры: список и фильтры, редактор с 7 вкладками, автосохранение (debounce), загрузка обложки и фото дней (MinIO, превью), drag-and-drop порядка дней.
- Финансовый калькулятор (`tourCalc`), план/факт, курсы с датой, сценарии, экспорт XLSX (ExcelJS, красиво оформленный).
- Публикация с проверками → создание выезда; дублирование; закрыть набор; архив; удаление.
- Генератор текста для Instagram, ссылки на посты/Reels.
- Публичная страница тура `/t/[slug]` (SSR, OG-теги, адаптив, анимации появления, кнопка WhatsApp с меткой для распределения).
- Выезды: план, карточка выезда (сетка мест, участники с шагом из заявки, «Открыть заявку», автоматизация задач), гиды и подбор гида (занятость, языки).

**Порядок работы:** сначала покажи план (файлы, модели, компоненты, риски) и дождись моего «ок». Потом реализация маленькими коммитами в ветке `feat/07-tours`. В конце: `pnpm lint && pnpm typecheck && pnpm test` зелёные, краткий отчёт «что сделано / как проверить / что осталось», открой PR.
