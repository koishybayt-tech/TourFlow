# Фаза 5. Заявки — главный экран

Это самая важная фаза. Сверяйся с прототипом и `docs/02_FEATURES.md` §4–5, §10.
- Список заявок: канбан (dnd, колонки с общим фоном и цветной полосой, сумма), список, фильтры, «Новая заявка» с поиском клиента и проверкой дублей.
- Страница заявки: шапка (ответственный, смена воронки, отказ), закреплённая навигация по шагам, 8 пронумерованных сворачиваемых блоков с итогом в свёрнутом виде, правая колонка (статус с выпадающим списком и «Осталось…», переписка, другие заявки клиента, заметки, история).
- Автостатус на сервере (`dealStatus`), анимация смены статуса, toast.
- Регламенты этапов: редактор в настройках.
- Задачи: системные задачи этапа (создание/закрытие), ручные с привязкой к этапу, карточка задачи (SlideOver) с кнопками «Взять в работу / Завершить с результатом / Вернуть», страница «Задачи» (список и канбан).
- Оплаты, возврат/перенос, документы (загрузка в MinIO), заметки, история (DealEvent).
- e2e: заявка «Жанна Ким» доходит от «Договор» до «Предоплата» только через заполнение данных.

**Порядок работы:** сначала покажи план (файлы, модели, компоненты, риски) и дождись моего «ок». Потом реализация маленькими коммитами в ветке `feat/05-deals`. В конце: `pnpm lint && pnpm typecheck && pnpm test` зелёные, краткий отчёт «что сделано / как проверить / что осталось», открой PR.
