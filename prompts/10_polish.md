# Фаза 10. Полировка: удобство, красота, анимации

Пройди по всем экранам как требовательный продуктовый дизайнер. Цель — интерфейс уровня Linear/Attio: спокойный, быстрый, понятный без обучения.
- Сверь каждый экран с `docs/04_DESIGN_SYSTEM.md`: отступы, иерархия, одно главное действие, пустые состояния, скелетоны, табличные цифры.
- Анимации из таблицы дизайн-системы (motion-v), `prefers-reduced-motion`.
- Микровзаимодействия: оптимистичные обновления, undo для удаления (toast «Отменить»), горячие клавиши (N — новая заявка, / — поиск, J/K — по списку), автосохранение с индикатором.
- Мобильная версия всех экранов, тёмная тема без артефактов.
- Доступность: клавиатура, фокус, aria, контраст.
- Производительность: Lighthouse ≥ 90 на публичной странице тура, ленивые компоненты, виртуализация длинных списков.
- Снимки экранов «до/после» по ключевым экранам в PR.

**Порядок работы:** сначала покажи план (файлы, модели, компоненты, риски) и дождись моего «ок». Потом реализация маленькими коммитами в ветке `feat/10-polish`. В конце: `pnpm lint && pnpm typecheck && pnpm test` зелёные, краткий отчёт «что сделано / как проверить / что осталось», открой PR.
