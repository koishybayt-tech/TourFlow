# Фаза 8. Пакетные туры и авиа/отели

По `docs/02_FEATURES.md` §9, §15.
- `TourSearchProvider`: mock (данные как в прототипе) + адаптер Tourvisor API (структура запросов, JWT, кэш справочников, асинхронный поиск с поллингом — без реального токена работает mock).
- Экран поиска с размещением по номерам (`roomAllocation`), результаты по отелям, «В подборку» из контекста заявки.
- Подборка в заявке: варианты, форма с проверками и наценкой, импорт варианта (парсинг текста; скриншот/PDF — через Claude API vision в `server/providers/ai`, ключ из env, mock по умолчанию), отправка подборки, «Клиент выбрал».
- Бронь у туроператора: статусы, оплаты оператору, аннуляция, документы оператора, предупреждение о кассовом разрыве. Реестр броней, справочник операторов.
- Авиабилеты и отели: экраны поиска (mock-провайдеры, колонка источника), мониторинг цен (pg-boss cron, уведомление).

**Порядок работы:** сначала покажи план (файлы, модели, компоненты, риски) и дождись моего «ок». Потом реализация маленькими коммитами в ветке `feat/08-package`. В конце: `pnpm lint && pnpm typecheck && pnpm test` зелёные, краткий отчёт «что сделано / как проверить / что осталось», открой PR.
