# Фаза 6. Шаблоны, договоры, подписание, расписки

По `docs/02_FEATURES.md` §7–8.
- Настройки → Реквизиты компании (валидация БИН, ИИК), Шаблоны: мастер загрузки DOCX → разбор переменных `{…}` (docxtemplater/pizzip) → связка с полями (автоподбор) → сохранение; предпросмотр на демо-заявке. Список расписок с переключателями.
- В заявке: мастер «Документ на подпись» (Шаблон → Предпросмотр → Заполнение полей → Подписание), генерация DOCX и PDF (Gotenberg), номер договора, ссылки подписи для клиента и агентства, отправка в WhatsApp.
- Публичная страница `/s/[token]` как на скриншотах эксперта: просмотрщик, лента подписантов, скачивание, «Подписать документ» → ЭЦП (NCALayer) / eGov Mobile (QR). `SigningProvider` mock + каркас NCALayer (WebSocket `wss://127.0.0.1:13579`, только подготовка интерфейса).
- Расписки в заявке: рекомендации по условиям, текст, на подпись, скан, «Отправить рекомендуемые».

**Порядок работы:** сначала покажи план (файлы, модели, компоненты, риски) и дождись моего «ок». Потом реализация маленькими коммитами в ветке `feat/06-docs`. В конце: `pnpm lint && pnpm typecheck && pnpm test` зелёные, краткий отчёт «что сделано / как проверить / что осталось», открой PR.
