# Фаза 3. Вход, роли, оболочка

- Страницы входа и регистрации агентства (layout auth), восстановление пароля по email (Mailpit в dev).
- Роли Владелец / Менеджер / Колл-центр: middleware, `usePermissions()`, проверка на сервере в каждом эндпоинте.
- AppShell: сайдбар по `docs/02_FEATURES.md` §1 (модули скрывают пункты, бейджи), шапка с поиском, ⌘K палитрой команд, уведомлениями, аватаром + именем + логином, меню профиля и переключателем темы.
- Переходы страниц и скелетоны по `docs/04_DESIGN_SYSTEM.md`.
- Главная «Мой день» (§2) на реальных данных.
- Настройки → Модули и Сотрудники и доступ (приглашение по email).
- e2e: вход владельцем и менеджером, менеджер не видит «Отчёты» и «Настройки».

**Порядок работы:** сначала покажи план (файлы, модели, компоненты, риски) и дождись моего «ок». Потом реализация маленькими коммитами в ветке `feat/03-shell`. В конце: `pnpm lint && pnpm typecheck && pnpm test` зелёные, краткий отчёт «что сделано / как проверить / что осталось», открой PR.
